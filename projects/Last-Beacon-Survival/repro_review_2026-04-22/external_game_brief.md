## 1. 题材 / 世界观 (D1 参考)

**背景设定** (Google Play 官方描述):
> 后启示录, 海平面持续上升, 世界被完全淹没。人类只能在漂浮于海洋的零散庇护所上挣扎求生。作为幸存者领袖, 玩家要带领人民搜集补给、建造庇护所、发展科技、击退入侵者, 最终在无尽海洋中生存下来。

**视觉主画面钩子** (封面图, Google Play 第 1/7/13 张 同一张画面重复 3 遍):
- 灯塔矗立在海面孤岛上, 灯塔下 5 个幸存者围着篝火, 远处海面乌云压顶、鲨鱼群环绕
- LOGO: `LAST BEACON` + `SURVIVAL` 副标
- 情感调性: **"绝望海洋中守护最后一点光"** — 有强烈孤独感+温暖核心的戏剧张力

**差异化定位**:
- 市场现状: Last War (末日陆地数字战争) / Whiteout Survival (冰雪末日 + 模拟经营) 已占据主要非传统 4X SLG 题材
- **海洋末日** 题材是 4X SLG 的**蓝海**, 没有出现年收入 10 亿美元级爆款
- Last Beacon 试图填这个空位

**题材层隐患 (D1 要重点讨论)**:
- 封面图 cover (灯塔/篝火/守护) 卖的是**情感叙事调性**
- 玩法图(基地/采集/战斗/抽卡) actual gameplay (建造+小队战+抽卡+联盟战) 卖的是**重度 SLG 肝氪调性**
- **二者割裂**: 被 封面图 情感钩子吸引的玩家 (偏剧情/氛围党) 可能在实玩中发现这是传统 SLG 套路, 产生心理落差 → 新手期流失风险高

## 2. 核心玩法循环 (D2 / D3 / D4 参考)

### 2.1 通过 18 张商店截图识别出的 6 个核心场景

| # | 标题 | 类型 | 观察要点 |
|---|---|---|---|
| **A** | Cover 灯塔孤岛 | 情感主画面 | 次世代 3D 渲染, 冷蓝海 + 暖黄灯塔光对比 |
| **B** | REBUILD THE SHELTER | 俯视基地建造 | 中央灯塔 + 6-8 个木结构模块, 木桥连接, 典型 SLG city-builder 视角 |
| **C** | EXPLORE AND COLLECT | 资源点采集 | 小岛棕榈树 + 幸存者采集 (+100 飘字奖励), 远处有鲨鱼 PVE 威胁 |
| **D** | PROTECT YOUR HOME | 基地防御战 | 瞭望塔 + 幸存者持鱼叉 vs 跳出水面大鲨鱼 BOSS |
| **E** | LEAD YOUR SQUAD | 小队战斗 | 俯视小队 (4-5 英雄) vs 红色怪物群 + 650 HP BOSS, 右侧英雄卡栏 |
| **F** | Dylan S 级英雄 | 抽卡养成页 | 海神造型三叉戟英雄, S 品级, LV.23, 钻石 1,125,841 + 装备槽 + 技能 + 属性 (9284/7271/563) |

**18 张里 12 张是上面 6 个场景的重复展示** —— 开发商主动选择"6 图 × 3 遍"策略, 要么是 A/B 测试 cover 顺序, 要么是**玩法深度本身就这 6 种, 靠重复占满 store**。

### 2.2 推断的主循环 (D2)

基于 6 个场景 + 商店文案, 主循环可能是:

```
新手开局 (封面图 篝火意象) 
  → 基地模块建造 (基地图, 用木材/资源/时间)
  → 外出探索采集资源 (采集图, 放置/异步, +100 飘字暗示被动奖励)
  → 遭遇威胁 (防御战图 基地被海怪攻击 / 联盟战图 小队被怪物群围攻)  
  → 打赢奖励 (英雄装备/钻石/卡)
  → 英雄抽卡养成 (抽卡图 Dylan S 品级, 钻石货币 1M+ 级, 说明深度养成)
  → 联盟系统 (仅文案提到, 截图未覆盖): "加入/创建联盟, 占海上要塞"
  → 循环: 资源→建造→战斗→抽卡英雄→更强→打更难的关/联盟战
```

**这是标准的 4X SLG 主循环, 没有结构性创新**。差异化全在"**海洋**"这个皮 (木筏/灯塔/鲨鱼), 不是核心循环机制。

### 2.3 时间节点 (D3) — **信息不足, 评委应降信度打分**

- 商店截图只展示**静态画面**, 不知道"5min/15min/30min/Day1→Day2" 的节奏感。
- 从 基地图 资源数字看 (木材 20/20, 人口 105.2M, 钻石 140,567) — **基地图 是中后期账号状态**, 不是开局
- 推测该游戏延续传统 SLG 的异步时间节点 (建造 N 分钟完成, 探索 N 小时, 战斗即时), 但**无实玩证据**

### 2.4 阶段过渡 (D4) — **信息不足, 评委应降信度打分**

- 100,000+ 安装量 + 无评分 → 游戏还未运营到足够成熟, 没有公开长期玩家数据佐证 "放置→沉浸→指挥→外扩" 的阶段过渡
- 英雄 抽卡图 Dylan LV.23 + 99M+ 钻石 + S 品级 → 暗示存在至少 LV30+ 英雄深度, 战力数字 19.1M (联盟战图) 说明联盟战/跨服战有战力对比体系
- **无法判断阶段过渡是否做得好**, 只能说框架上是完整的 (基建→英雄→联盟 三层)

## 3. 美术 / 配色 / 素材 (D7 参考)

**美术制作质量**:
- **高** — 次世代 3D 渲染质量, 光影有层次 (封面图 灯塔暖黄 + 海面蓝 + 云层明暗), 人物造型精致 (Dylan 抽卡图 海神肌肉/三叉戟/装饰有细节)
- 非 chibi / 卡通路线, 偏**写实风**, 目标用户: 8-45 岁硬核 SLG 偏好者, 不是放置萌系用户

**配色策略**:
- **主色调**: 冷蓝 (海) + 暖黄橙 (灯塔光 / 篝火)
- 识别度高, 跟 Whiteout Survival (冰蓝+暖橙) / Last War (废土黄 + 红) 形成明显区分
- 抽卡图 英雄页切换到纯蓝底 (海神氛围), UI 配色跟世界观一致

**美术跟玩法的一致性 (D1 + D7 交叉问题)**:
- 封面图 (cover) 叙事调性: 诗意 / 孤独 / 希望
- 玩法图(基地/采集/战斗/抽卡) UI/战斗调性: 信息密度高 / 商业化入口明显 / 数字战力比拼
- **二者不一致** — 美术花了成本, 但没有把"题材氛围"贯穿到 UI/战斗场景

**营销素材判断**:
- 18 张截图 6 独立 × 3 重复 → 商店 listing 信息密度**偏低**, 买量素材可能依赖 UGC/广告创意发挥
- 无 GIF/视频展示位 (Google Play 支持但开发商没放) → 转化率可能吃亏

## 4. 商业化 (D5 参考)

### 4.1 直接观察到的商业化元素

| 场景 | 商业化信号 |
|---|---|
| 基地图 右上 | 红圈钻石 `140,567` + 购物车图标, 付费入口明确 |
| 抽卡图 | Dylan S 品级 (说明有 S/A/B/C 品级稀有度 → 抽卡系统) |
| 抽卡图 | 钻石数字 `1,125,841` (硬通货), 装备槽 3 个 + 技能 4 个 + 属性 3 项 = 深度养成 |
| 联盟战图 | 英雄卡栏 4-5 个 + 战力对比 16.4K vs 19.1M (巨大差距 → 付费战力拉升空间大) |

**商业化模型**: 典型 **F2P + 抽卡 + 战力付费** SLG 三件套, **没有创新**, 但这是当前最成熟可靠的 ARPDAU 模型。

### 4.2 Benchmark 对比 (真实市场数据, 作为 D5 评分锚点)

| 游戏 | ARPDAU | D30 留存 | MAU (2024-12) | 年收入 (2024) |
|---|---|---|---|---|
| **Last War: Survival** | $2.47 | 4% | 4000 万+ | $11 亿+ |
| **Whiteout Survival** | $1.08 | 8% | 2000 万+ | $19 亿 (累计) |
| **Last Beacon: Survival** | **无公开数据** | **无公开数据** | 100K+ 安装量 (早期) | **无公开数据** |

**对 Last Beacon 的推断**:
- 小厂 + 100K 早期安装量, 距离 Last War/Whiteout 的 2000-4000 万 MAU 差 **2 个数量级**
- 商业化模型跟大厂一致, 说明**不是通过模型革新弯道超车**, 只能靠题材 (海洋) 差异化
- 最乐观: 成为"海洋 SLG 的小众长尾", ARPDAU $0.5-1.0 / D30 3-5% / MAU 50-200 万区间
- 最悲观: 1 年内因没买量支撑和大厂挤压, 项目停运

### 4.3 D6 合规风险

- **题材**: 海洋+灯塔+孤岛 → 零政治/历史/色情敏感, 低风险
- **抽卡 (抽卡图 暗示存在)**: 中国/韩国/比利时需要披露概率, 巴西最近对 loot box 也收紧
- **厂商 HK 主体**: 规避了大陆游戏审批的主体压力, 但进入大陆市场仍需版号, 且从题材推断**厂商没有打算进大陆**, 主攻欧美/东南亚
- **用户协议 + GDPR**: 作为出海 SLG 标配, 假定已做 (无直接证据)

### 8.3 关键发现 (按维度)

#### D1 主题匹配 — **主题递减现象** (重大下调)

视频证据证实存在"**开局情感 → 后期纯 SLG**"的单向衰减:

- **Shorts (0-3 分钟 新手)**: `Bab 1 Bertahan di Laut` (海上生存) 任务 + 木筏子基地 + 篝火 + 主角持火把 → 主题强烈

### 8.5 Skill 层发现 (跟踪到 MVP_A_reflection.md)

本次视频流程同时暴露了 3 个 ppt-master skill 层的 bug/gap:

1. **`_heuristic_label` 对竖屏帧系统性误判**: ratio < 0.7 即判 ui-menu, 导致 80 帧竖屏手游录像一张都没送 AI. 绕过方案: 一次性脚本 `scripts/direct_label.py`
2. **`fetch_gameplay` 硬编码 ytsearch**: 无法接受用户手动指定的 URL. 绕过方案: 直接 `yt-dlp <url>`
3. **`argparse` 前缀匹配**: `--game` 前缀匹配到 `--gameplay-only` 导致互斥错误. 绕过方案: 用 positional `game` 参数

这些 bug 在本次外部游戏评审中全部被绕过, 但应该在 skill B 阶段系统修复。
